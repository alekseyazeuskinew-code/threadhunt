# Публикация расширения в Chrome Web Store — готовый листинг

Всё, что нужно вставить в Developer Console. Тексты ниже можно копировать как есть.

## 0. Что подготовить заранее
- [ ] Аккаунт разработчика Chrome (разовый сбор **$5**): https://chrome.google.com/webstore/devconsole
- [ ] Файл **`packages/extension/threadhunt-extension.zip`** (уже собран; пересобрать — `node build.mjs`, затем `cd dist && zip -rq ../threadhunt-extension.zip .`)
- [ ] **Скриншоты** 1280×800 (мин. 1, лучше 3–5) — см. раздел 5.
- [ ] (опц.) Промо-плитка 440×280.

## 1. Создать запись
1. Открой https://chrome.google.com/webstore/devconsole → оплати $5 (один раз).
2. **New item** → перетащи `threadhunt-extension.zip` → Upload.

## 2. Store listing — тексты (вставить как есть)

**Название (Item title):**
```
Threadhunt — авто-отбивка в директе Threads
```

**Краткое описание (Summary, до 132 символов):**
```
Авто-ответы в директе Threads по вашим кодовым словам — прямо в браузере. Отклики превращаются в кандидатов в Threadhunt.
```

**Подробное описание (Description):**
```
Threadhunt автоматизирует найм через Threads.

Это расширение — «руки» сервиса в директе: оно само отвечает на входящие сообщения, в которых есть заданные вами кодовые слова (например «монтаж», «дизайн», «резюме»), и помечает диалог как обработанный. Работает в вашем браузере, под вашей же сессией Threads — никаких паролей и доступов Meta не требуется.

Как это работает:
1. Зарегистрируйтесь в Threadhunt и подключите браузер в один клик.
2. Задайте кодовые слова и шаблоны ответов под вашу вакансию.
3. Расширение проходит по директу (включая «Запросы» и «Скрытые»), отвечает на подходящие сообщения и аккуратно соблюдает паузы между ответами.
4. Каждый отклик попадает в вашу CRM в Threadhunt — дальше ведёте кандидата по этапам.

Безопасность аккаунта:
— Встроены лимиты: задержки между ответами, лимит диалогов за проход, рабочие часы.
— Расширение действует только в вашем браузере и не хранит ваши пароли/cookie.

Для работы нужен аккаунт Threadhunt (есть бесплатный тариф).
```

**Категория:** Productivity
**Язык:** Russian (можно добавить English отдельным переводом позже)

## 4. Privacy practices (важно — без этого не одобрят)

**Single purpose (одно предложение):**
```
Расширение автоматически отвечает на входящие сообщения в директе Threads, содержащие заданные пользователем кодовые слова, от имени пользователя и в его собственном браузере.
```

**Обоснование разрешений (Permission justification):**
- `storage`:
```
Хранит локально код привязки к аккаунту Threadhunt, адрес сервера и состояние текущего прохода по директу (чтобы продолжать после перезагрузки страницы).
```
- `alarms`:
```
Периодически отправляет heartbeat и получает с аккаунта пользователя актуальные правила ответов (кодовые слова и шаблоны).
```
- Host `https://www.threads.com/*`, `https://www.threads.net/*`:
```
Чтение входящих сообщений в директе и отправка ответов от имени пользователя — основная функция расширения.
```
- Host `https://threadhuntserver-production.up.railway.app/*` (и `https://api.threadhunt.app/*`):
```
Связь с аккаунтом пользователя в Threadhunt: получение правил ответов и передача отметок о том, какие диалоги уже обработаны (для CRM).
```
- Host `http://localhost:3010/*`:
```
Локальная разработка и тестирование.
```

**Раскрытие использования данных (Data usage) — что отметить:**
- Собираемые данные: **Personally identifiable information** → юзернеймы авторов входящих сообщений (для создания карточки кандидата в CRM).
- НЕ отмечать: пароли/данные аутентификации, история браузера, местоположение, финансы.
- Поставить галочки:
  - ✅ «Данные используются только для основной функции сервиса».
  - ✅ «Данные не продаются третьим лицам».
  - ✅ «Данные не используются для целей, не связанных с заявленной».

## 5. Скриншоты (сделай сам, 1280×800 PNG)
Сними 3–5 кадров (можно с демо-аккаунта `demo@threadhunt.app`):
1. Дашборд «Обзор» с данными.
2. Поиск → вкладка «Кодовые слова» и «Отбивка» (шаблоны ответов).
3. Кандидаты (CRM-пайплайн).
4. Попап расширения (подключено) + страница «Подключения».
5. (опц.) Директ Threads с автоответом.
Как привести к 1280×800: скриншот окна → подгони размер в любом редакторе/Preview.

## 6. Отправка
- Заполни обязательные поля (помечены) → **Submit for review**.
- Модерация обычно несколько дней — до ~недели.
- После одобрения получишь ссылку на расширение в Store — её даёшь пользователям (и пропиши в кнопку «Установить» на странице «Подключения», переменная `NEXT_PUBLIC_EXT_STORE_URL` на Netlify).

## 7. После публикации — связать с сайтом
В env веба (Netlify) добавь:
```
NEXT_PUBLIC_EXT_STORE_URL=https://chromewebstore.google.com/detail/<твой-id>
```
Тогда на странице «Подключения» кнопка «Установить» поведёт прямо в Store.
