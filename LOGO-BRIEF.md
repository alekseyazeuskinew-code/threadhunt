# Threadhunt — бриф для генерации логотипа и брендбука

> Можно целиком передать другой нейросети. Ниже — суть бренда, стиль, цвета, шрифты и готовые промпты.

## 1. О продукте
- **Название:** Threadhunt (пишется слитно, строчными в лого).
- **Смысл:** Thread(s) + headhunt — хедхантинг через соцсеть Threads.
- **Что это:** SaaS-сервис, который автоматизирует наём через Threads — авто-постинг «цепляющих» постов-приманок и авто-ответы в директе по кодовым словам, плюс CRM-воронка кандидатов.
- **Позиционирование:** «VIP-хедхантинг через Threads на автопилоте». Лента Threads → поток кандидатов.
- **Аудитория:** малый бизнес, небольшие команды, HR-специалисты, фрилансеры, собирающие свою команду.

## 2. Характер бренда (tone of voice)
Уверенный, дружелюбный, по делу. Минимум маркетингового шума, максимум конкретики. Обращение на «ты». Современный, технологичный, но человечный. Глаголы действия: создай, запусти, поймай, направь. Эмодзи — точечно.

Ассоциации для визуала: **нить / ткачество / игла / катушка** (Threads = нити), **прицел / охота** (hunt), **воронка лидов**. Цель — поймать и сплести команду.

## 3. Логотип

**Концепт знака:** игла с нитью, где нить складывается в «галочку-прицел» (поймано/в точку). Альтернатива — две наклонные нити-штриха `⟋⟋`, которые читаются и как нити, и как «движение/скорость».

**Вордмарк:** `threadhunt` — строчными, плотный трекинг (tight), вес 600–700, шрифт Space Grotesk. Перед словом — лаймовый знак (две наклонные нити).

Нужны версии:
- горизонтальный вордмарк (знак + текст);
- только знак (иконка, квадрат, для фавикона/аватара);
- монохром (на тёмном и на светлом);
- фавикон 32×32 (знак в квадрате на почти-чёрном фоне, лаймовый знак по центру).

**Стиль знака:** геометрично, минималистично, тонкая обводка или сплошная заливка лаймом; без градиентов и объёма; «дев-тул / премиум-SaaS».

## 4. Цвета (палитра «Lime-заряд»)
Тёмная тема по умолчанию, один яркий акцент.

| Роль | HEX |
|---|---|
| Фон (основной) | `#0B0B0F` |
| Панели/карточки | `#14141A` |
| Вложенные блоки | `#1C1C24` |
| Границы | `#26262F` |
| Текст основной | `#EDEDF2` |
| Текст вторичный | `#8A8A99` |
| **Акцент (лайм)** | `#C6F24E` |
| Акцент (нажатие) | `#B2DE3C` |
| Успех | `#4ADE80` |
| Ошибка | `#FB7185` |
| Предупреждение | `#FBBF24` |

Правило: лайм — только для главного действия и акцентов, не больше одного «зелёного» пятна в кадре. Текст на лайме — тёмный (`#0B0B0F`), не белый.

## 5. Шрифты
| Роль | Шрифт |
|---|---|
| Заголовки / логотип | **Space Grotesk** (600–700, трекинг tight) |
| Текст / интерфейс | **Inter** |
| Цифры / данные / код | **JetBrains Mono** |
Все три — бесплатные (Google Fonts).

## 6. Визуальный стиль (для брендбука и графики)
- Тёмный минимализм, много воздуха, крупная типографика заголовков.
- Скругления: карточки `rounded-2xl` (~16px), кнопки и чипы — `rounded-full`.
- Иконки: outline, тонкая обводка (стиль lucide), заливка только в активном состоянии (лайм).
- Никаких градиентов-радуг, теней-объёма, стоковых «бизнес-рукопожатий».
- Эстетика: Linear / Vercel / Raycast, но с энергичным лаймовым акцентом.

## 7. Что попросить сгенерировать
1. Логотип: знак + горизонтальный вордмарк (на тёмном и светлом), монохром, фавикон.
2. Брендбук (1 PDF): логотип и его версии, охранное поле, палитра с HEX, шрифтовая пара, примеры «правильно/неправильно», тон-оф-войс, примеры применения (аватар соцсетей, шапка, кнопка, карточка).
3. Соц-аватар 1:1 и обложку.
